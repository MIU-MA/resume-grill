# 岗位详情与进展

在“投递记录”中选择岗位，右侧可切换岗位要求、简历与投递、面试与复盘、求职进展。待投递岗位从清单操作栏的“资料”进入。

- **求职进展**：手动记录回复、约面试、下一轮、未通过、Offer 或结束跟进，填写联系人、面试时间、跟进时间、下一步和备注，点击“保存进展”。左侧可按进展筛选。时间仅用于记录，不会发送通知。
- **岗位要求**：继续使用已有的简历检查和面试准备。修改当前 JD 不会改动投递时的快照。
- **简历与投递**：新提交的邮件保留最终批次中的实际附件，可下载核对；官网申请保留手动登记时选中的简历，不代表已验证官网附件。旧记录不会用当前附件冒充历史附件。
- **面试与复盘**：只列出关联此岗位 ID 的练习，可打开已有准备与复盘；真实面试可单独记录轮次、时间、问题和复盘，并再次修改。

进展、笔记、快照和已读取的邮件记录保存在当前浏览器的 IndexedDB。执行器断开后仍可查看；邮件状态为上次读取结果，重试或取消发送需要重新连接执行器。清理浏览器站点数据会删除这些本地资料。

邮件的排队、失败、已提交邮箱与求职进展分开记录。发送成功不代表对方已经阅读或回复，面试和 Offer 状态不会自动猜测。
