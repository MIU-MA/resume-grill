# 发布前检查

首个对外版本建议使用 `v0.1.0-beta.1`。网页和邮箱流程可按实际验证情况介绍；官网填写统一标为实验性，当前各站验证范围见 [适配记录](website-adaptation.md)。

## 发布包

`npm run build` 会生成官网填写扩展；再运行 `npm run release:assets`，在 `dist/release/` 得到：

- `resume-grill-website-extension.zip`
- `SHA256SUMS.txt`

下载后可用 PowerShell 的 `Get-FileHash 文件名 -Algorithm SHA256` 或 Linux 的 `sha256sum -c SHA256SUMS.txt` 核对。解压后在 Chrome / Edge 开启开发者模式，加载 `website-extension` 文件夹。升级前先完成当前任务；不要删除扩展以免清除本地任务。

推送 `v*` 标签后，Release 工作流先检查和构建，再上传安装包与校验值；带连字符的标签发布为 prerelease。发布说明由 GitHub 根据标签生成。GHCR 镜像独立构建，镜像失败不阻止下载已验证的扩展包。网页容器不包含本机邮箱执行器。

## 维护者验收

- 从干净检出运行 `npm ci`，确认 Linux / Windows CI 均通过；检查 Git 历史、截图与示例中没有凭据或个人信息。
- 用示例材料验证导入、修改、导出 PDF、岗位加入清单、重启恢复；不使用真实收件人验证自动发送。
- 在本机检查 `npm run dev:local`：网页和执行器一起启动；端口占用报错；退出后两项服务停止，未完成邮件不会自动重发。
- 官网至少选两家代表性站点，使用个人授权的登录会话逐项记录基本资料、多段经历、附件与校对结果。手动最终提交不属于自动化测试。未完成时保留“未实测”，不能仅凭单元测试宣称兼容。
- 更新 README 中的真实截图；关闭连接码、授权码、真实邮箱和个人简历展示。
- 开启仓库的私密漏洞报告入口，确认发布说明包含平台要求、实验性功能和已知限制。

本文件是验收清单，不表示上述登录实测或首次安装验收已完成。
