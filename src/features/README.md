# Feature 目录约定

每个目录对应一个用户可识别的业务模块，模块内放视图、子组件以及仅由该模块使用的类型和配置。

- `audit`：能力清单与要点详情
- `interview`：模拟面试与进度面板
- `knowledge`：复习笔记与知识点
- `report`：面试报告与改写建议
- `resume`：简历导入、确认和历史记录
- `settings`：模型配置
- `workspace`：业务模块的导航与页面编排

跨模块约定：

- 可复用的视觉控件放在 `src/components/ui`。
- 业务规则和数据结构放在 `src/domain`。
- 无界面的纯函数、存储和服务端工具放在 `src/lib`。
- 跨模块状态编排放在 `src/hooks`，应用入口与公共契约放在 `src/application`。
- 模块之间只导入明确需要的文件，不增加汇总导出文件，避免循环依赖。
