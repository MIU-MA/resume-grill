# 简历拷打机

从简历里的技术声明出发，生成递进追问，并检查回答是否覆盖了关键证据。

它不是随机八股题库。每组问题都绑定一条简历原文，沿着「原理 -> 实现 -> 异常 -> 排障 -> 边界」逐层深入。

## Demo 能力

- 将简历拆成可追问的技术声明
- 展示风险等级、已有证据与证据缺口
- 为每条声明生成递进问题树
- 模拟面试并给出本地回答评分
- 标记回答命中点和建议补充项
- 导出 Markdown 风险报告
- 支持桌面、平板和手机布局

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run lint
npm run build
```

## 当前实现

当前版本是无需 API 的交互 Demo。示例声明来自一份真实前端简历，分析、问题树和回答评分均在浏览器本地运行，方便先验证产品交互。

接入真实模型时，建议把流程拆成三个服务端步骤：

1. PDF 文本提取与结构化
2. 技术声明、证据和风险点识别
3. 根据当前回答动态生成下一层问题与评分依据

API Key 应只保存在服务端环境变量中，不应下发到浏览器。
